1. INTRODUCTION                                             *haft-introduction*

haft.nvim is a Neovim plugin that integrates the Haft CLI - a Spring Boot
productivity tool - directly into Neovim.

Features:~
    - Full integration with all Haft CLI commands
    - Project initialization (TUI/Wizard/Quick modes)
    - Code generation for all Spring Boot components
    - Dependency management with Telescope pickers
    - Development server with hot-reload and auto-restart
    - Project health checks and statistics
    - Template management and customization
    - Floating windows for detailed output
    - Async command execution (non-blocking)
    - Auto-detection of Haft/Spring Boot projects

==============================================================================
2. REQUIREMENTS                                             *haft-requirements*

Required:~
    - Neovim >= 0.9.0
    - Haft CLI >= 0.1.16 (https://github.com/KashifKhn/haft)
    - plenary.nvim (https://github.com/nvim-lua/plenary.nvim)

Optional (Recommended):~
    - telescope.nvim - Interactive pickers
    - noice.nvim - Enhanced notifications
    - nui.nvim - UI components

4. CONFIGURATION                                           *haft-configuration*

Call `require("haft").setup(opts)` to configure the plugin.

                                                              *haft-config-opts*
Default configuration:~
>lua
    require("haft").setup({
      haft_path = "haft",

      detection = {
        enabled = true,
        patterns = { ".haft.json", "pom.xml", "build.gradle", "build.gradle.kts" },
      },

      notifications = {
        enabled = true,
        level = "info",
        timeout = 3000,
      },

      float = {
        border = "rounded",
        width = 0.8,
        height = 0.8,
        title_pos = "center",
      },

      picker = {
        provider = "auto",
        telescope = {
          theme = "dropdown",
          layout_config = { width = 0.8, height = 0.6 },
        },
      },

      auto_open = {
        enabled = true,
        strategy = "first",
      },

      quickfix = {
        enabled = true,
        auto_open = false,
      },

      terminal = {
        type = "auto",
        float = { border = "rounded", width = 0.8, height = 0.8 },
        split = { size = 15, position = "below" },
        persist = true,
        auto_close = false,
      },

      dev = {
        restart_on_save = false,
        save_patterns = { "*.java", "*.kt", "*.xml", "*.yaml", "*.yml", "*.properties" },
      },

      init = {
        mode = "tui",
        after_create = "prompt",
        auto_cd = true,
        auto_open = true,
      },
    })
<

5. COMMANDS                                                     *haft-commands*

------------------------------------------------------------------------------
PROJECT INITIALIZATION                                   *haft-commands-init*

                                                                     *:HaftInit*
:HaftInit [mode]~
    Initialize a new Spring Boot project.
    - No args: Opens mode picker (tui/wizard/quick)
    - `tui`: Opens Haft TUI wizard (LazyGit-style)
    - `wizard`: Opens Neovim native wizard
    - `<name>`: Quick create project with given name

                                                                  *:HaftInitTui*
:HaftInitTui~
    Initialize project using Haft TUI wizard directly.

                                                               *:HaftInitWizard*
:HaftInitWizard~
    Initialize project using Neovim native wizard.

                                                                *:HaftInitQuick*
:HaftInitQuick [name]~
    Quick create project with default settings.

------------------------------------------------------------------------------
PROJECT INFORMATION                                       *haft-commands-info*

                                                                     *:HaftInfo*
:HaftInfo~
    Show project information in a floating window.

                                                                   *:HaftRoutes*
:HaftRoutes~
    Show API routes in a floating window.

                                                                    *:HaftStats*
:HaftStats [cocomo]~
    Show code statistics in a floating window.
    - `cocomo`: Include COCOMO cost estimates

                                                                   *:HaftDoctor*
:HaftDoctor [category] [strict]~
    Run project health check.
    - `<category>`: Check specific category (build/source/config/security)
    - `strict`: Treat warnings as errors

------------------------------------------------------------------------------
DEPENDENCY MANAGEMENT                                      *haft-commands-deps*

                                                                      *:HaftAdd*
:HaftAdd [dependency...]~
    Add dependencies to the project.
    - No args: Opens Telescope picker to select dependencies
    - With args: Adds specified dependencies directly
    
    Example:~
>vim
        :HaftAdd lombok
        :HaftAdd jpa validation web
<

                                                                   *:HaftRemove*
:HaftRemove [dependency...]~
    Remove dependencies from the project.
    - No args: Opens Telescope picker with current dependencies
    - With args: Removes specified dependencies directly

------------------------------------------------------------------------------
CODE GENERATION                                        *haft-commands-generate*

                                                         *:HaftGenerateResource*
:HaftGenerateResource [name]~
    Generate a complete CRUD resource (Controller, Service, Repository,
    Entity, DTOs, Mapper).

                                                       *:HaftGenerateController*
:HaftGenerateController [name]~
    Generate a REST controller.

                                                          *:HaftGenerateService*
:HaftGenerateService [name]~
    Generate a service interface and implementation.

                                                       *:HaftGenerateRepository*
:HaftGenerateRepository [name]~
    Generate a JPA repository interface.

                                                           *:HaftGenerateEntity*
:HaftGenerateEntity [name]~
    Generate a JPA entity class.

                                                              *:HaftGenerateDto*
:HaftGenerateDto [name]~
    Generate Request and Response DTO classes.

                                                        *:HaftGenerateException*
:HaftGenerateException [all]~
    Generate global exception handler.
    - `all`: Generate all exception types

                                                           *:HaftGenerateConfig*
:HaftGenerateConfig [all]~
    Generate configuration classes (CORS, OpenAPI, Jackson, etc.).
    - `all`: Generate all config classes

                                                         *:HaftGenerateSecurity*
:HaftGenerateSecurity [type]~
    Generate security configuration.
    - `jwt`: JWT authentication
    - `session`: Session-based authentication
    - `oauth2`: OAuth2 authentication
    - `all`: All security configurations

6. TELESCOPE                                                   *haft-telescope*

The plugin provides a Telescope extension with interactive pickers.

                                                     *haft-telescope-extension*
Load Extension:~
>lua
    require("telescope").load_extension("haft")
<

                                                       *haft-telescope-pickers*
Available Pickers:~
>vim
    :Telescope haft dependencies    " Browse and add dependencies
    :Telescope haft remove          " Browse and remove dependencies
    :Telescope haft routes          " Browse API routes (jump to source)
    :Telescope haft templates       " Browse templates (open/init)
<

Via Lua:~
>lua
    require("telescope").extensions.haft.dependencies()
    require("telescope").extensions.haft.remove()
    require("telescope").extensions.haft.routes()
    require("telescope").extensions.haft.templates()
<

Routes Picker:~
    - Browse all REST endpoints in your project
    - Preview shows handler details and file location
    - Press <CR> to jump to the route handler in source code
    - HTTP methods are color-coded

Templates Picker:~
    - Browse all available templates (project/global/embedded)
    - Icons indicate source: [P] project, [G] global, [E] embedded
    - Press <CR> to open custom template file
    - Press <C-i> to initialize templates for selected category

10. TROUBLESHOOTING                                       *haft-troubleshooting*

Haft CLI not found:~
    Ensure Haft CLI is installed and in PATH:
>bash
        haft --version
<
    Or set custom path:
>lua
        require("haft").setup({
          haft_path = "/path/to/haft",
        })
<

Telescope pickers not working:~
    1. Verify Telescope is installed: `:Telescope`
    2. Load extension: `:lua require("telescope").load_extension("haft")`
    3. Or switch to native picker:
>lua
        require("haft").setup({
          picker = { provider = "native" },
        })
<

Commands not working:~
    Most commands require being in a Haft project directory.
    Run `:HaftInfo` to check project detection.
    Look for pom.xml, build.gradle, or .haft.json in project root.

Dev server not restarting:~
    Ensure the server is running (`:HaftServe`).
    Check that trigger file patterns match your files.
    Try manual restart with `:HaftRestart`.
